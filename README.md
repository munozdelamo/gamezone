# 🎮 GameZone

Proyecto base para una práctica educativa de **HTML, CSS y JavaScript**.

## Estructura

```text
gamezone/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Objetivo

El alumnado deberá completar y mejorar la web GameZone aplicando los conceptos trabajados en clase.

## Propuesta de práctica

### 1. HTML
- Añadir nuevos juegos.
- Mejorar la estructura semántica.
- Crear un formulario de contacto.
- Añadir imágenes y enlaces.

### 2. CSS
- Personalizar colores y tipografías.
- Crear una interfaz responsive.
- Mejorar las tarjetas de juegos.
- Añadir animaciones y efectos `:hover`.

### 3. JavaScript
- Crear un buscador de juegos.
- Implementar filtros por categoría.
- Mostrar información de un juego mediante un modal.
- Añadir interacción a los botones.
- Crear un sistema sencillo de puntuación.

## Normas

- Mantener la estructura de carpetas.
- Utilizar nombres de clases descriptivos.
- Separar HTML, CSS y JavaScript.
- Comentar el código cuando sea necesario.
- Realizar commits descriptivos y frecuentes.

## Entrega

El proyecto deberá publicarse en un repositorio de GitHub y, si se solicita, desplegarse mediante **GitHub Pages**.

## Reto opcional

Añadir una sección de "Juegos más populares" cuyos datos se generen dinámicamente mediante JavaScript.
